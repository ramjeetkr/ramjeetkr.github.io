# Employee Management - React Frontend (Skeleton)
This is a starter React.js frontend for an **API-based** Employee Management system with modules:
- Attendance
- Payroll
- Employee Master
- Shift Management
- GatePass
- Approval Flow
- Master data related to employees

**Notes**
- This is a frontend-only skeleton. It expects a backend API at `/api/*`. If your ASP.NET API is available, configure `src/services/api.js` `baseURL`.
- If no backend is present, the included `api.js` will fall back to mocked data for local testing.

How to use:
1. `npm install`
2. `npm start`
